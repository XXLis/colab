# Data Analyse Project - Python

## Over dit project
Dit project is uitgevoerd als onderdeel van een intensieve programmeercursus. Het doel van de opdracht was om een dataset te analyseren, op te schonen en visueel weer te geven met behulp van Python en Google Colab.

## Functionaliteiten
* **Data Cleaning:** Verwijderen van duplicaten en afhandelen van ontbrekende waarden.
* **Exploratieve Data-analyse (EDA):** Statistieken genereren om inzicht te krijgen in de dataset.
* **Visualisaties:** Gebruik van grafieken om trends en patronen in de data te laten zien.

## Gebruikte Technologieën
* **Python 3**
* **Pandas:** Voor datamanipulatie.
* **Matplotlib / Seaborn:** Voor het maken van visuele grafieken.
* **Google Colab:** Als ontwikkelomgeving.

## Hoe dit project te gebruiken
1. Open het `.ipynb` bestand in Google Colab of Jupyter Notebook.
2. Zorg dat de benodigde bibliotheken zijn geïnstalleerd (`pip install pandas matplotlib seaborn`).
3. Voer de cellen stap voor stap uit om de analyse te bekijken.

## Conclusies
Uit de analyse kwamen enkele interessante inzichten naar voren [hier kun je een korte conclusie toevoegen, bijv.: zoals de correlatie tussen variabele A en variabele B].
